# Vimalakirti Sutra · 维摩诘所说经

A personal bilingual study site for the Vimalakirti Sutra, one of nine scripture mini sites under [The Dharma Gate](https://lugh3456.github.io/DharmaGate/) portal.

## What it is

A chapter-by-chapter study companion for the Vimalakirti Sutra (维摩诘所说经), divided into 14 chapters following the Kumārajīva translation (鸠摩罗什译, T0475). Each chapter presents the full Chinese text with speech synthesis, followed by explanation cards with Chinese explanations and expandable detailed English commentary.

## Features

- Bilingual Chinese/English throughout
- Default view shows Chinese explanations only (concept-focused, accessible register)
- Expandable "English ▾" toggle reveals English translation + full English commentary
- Bilingual summary at the end of each chapter (Chinese default, expandable English)
- Speech synthesis for full Chinese text (Web Speech API, Ting-Ting voice)
- Portal bar linking back to The Dharma Gate hub
- Mobile-optimised, responsive layout

## Source text

Kumārajīva translation (鸠摩罗什译), Taishō Tripiṭaka No. 475 (T0475), sourced from CBETA digital edition.

## Tech stack

- Pure HTML + external CSS, no frameworks
- CSS design tokens (red/saffron colour scheme, shared with DiamondSutra and LotusSutra)
- Google Fonts: Noto Serif SC + Noto Sans SC
- No build step required
